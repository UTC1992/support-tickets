# Naming Rules

- Componentes React: `PascalCase`, ejemplo `LoginForm.tsx`.
- Hooks: `usePascalCase`, ejemplo `useSession.ts`.
- Servicios/helpers: `kebab-case.ts`, ejemplo `auth-service.ts`.
- Funciones: preferir arrow functions.
- Usar `export default` al final cuando el archivo tenga un solo export principal.
- En Route Handlers de Next usar exports nombrados requeridos: `GET`, `POST`, `PATCH`, etc.
- Commits con Conventional Commits: `feat:`, `fix:`, `chore:`, `docs:`.
